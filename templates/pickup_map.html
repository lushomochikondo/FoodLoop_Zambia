Choose the collection point

Choose a collection point anywhere in Zambia. Pin the entrance where collections take place. You can select it on the map or enter coordinates. Opening the map loads map tiles from OpenStreetMap.

Town shortcuts move the map only. Tap the actual collection entrance to set the pin. You can pan and zoom to any other location.

The exact pin stays private until acceptance unless you enable “Share pickup pin” above. Otherwise, eligible organisations see only an approximate area for journey planning. Report a map issue.
